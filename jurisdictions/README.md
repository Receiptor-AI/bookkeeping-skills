# Jurisdictions

Bookkeeping principles are general. Tax treatment, filing thresholds, deduction limits, sales tax/VAT, payroll, and statutory record rules are jurisdiction-specific.

Use this folder when a skill needs rules for a specific country or tax system.

## Current packs

| Jurisdiction | Status | File | Use for |
|---|---|---|---|
| United States | Active baseline | [us.md](us.md) | US small-business expense categorization, Schedule C mapping, 1099 readiness, estimated taxes, depreciation, meals, vehicle, and home-office rules |

## Agent policy

1. Determine the user's tax jurisdiction before applying tax, deduction, filing, payroll, sales tax, VAT, or statutory reporting rules.
2. If jurisdiction is unknown, continue only with jurisdiction-neutral bookkeeping work: evidence capture, transaction normalization, source trails, review queues, and reconciliation structure.
3. Load the jurisdiction file before using a jurisdiction-specific skill.
4. Treat year-specific amounts, thresholds, rates, and deadlines as current-law facts that require verification against primary sources before final use.
5. Do not blend rules across countries. If a business operates in multiple jurisdictions, create separate notes for each jurisdiction and flag the case for professional review.

## What belongs here

- Country-specific tax forms and reporting lines
- Deduction limits and documentation requirements
- Filing thresholds, rates, and deadlines
- Payroll, contractor, VAT, GST, sales tax, or information-return rules
- Record-retention requirements
- Local terminology that affects chart-of-accounts mapping
